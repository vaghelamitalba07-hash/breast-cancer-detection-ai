The ML Model

Trained on gold-standard medical data

📚 Dataset

Wisconsin Diagnostic Breast Cancer (WDBC) from UCI Machine Learning Repository

  • 569 biopsy samples
  • 357 Benign (62.7%)
  • 212 Malignant (37.3%)
  • Validated by medical professionals

🌲 Algorithm

Random Forest Classifier with 100 decision trees

  • Ensemble learning for robustness
  • Balanced class weights
  • Feature importance scoring
  • Out-of-bag error estimation

🔬 30 Morphological Features

• Radius (mean/se/worst)
• Texture (mean/se/worst)
• Perimeter (mean/se/worst)
• Area (mean/se/worst)
• Smoothness (mean/se/worst)
• Compactness (mean/se/worst)
• Concavity (mean/se/worst)
• Concave Points (mean/se/worst)
• Symmetry (mean/se/worst)
• Fractal Dimension (mean/se/worst)

📊 Performance Metrics

  • Sensitivity: 96.9% (at 0.3 threshold)
  • Specificity: 97.2%
  • ROC-AUC: 0.990
  • F1 Score: 0.967
