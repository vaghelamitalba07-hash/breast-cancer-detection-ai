📖 How It Works

The model uses a Random Forest classifier with 100 decision trees trained on 569 biopsy samples from the UCI Wisconsin Breast Cancer Dataset. It analyzes 30 morphological features (radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, fractal dimension - each measured as mean, standard error, and worst value).
